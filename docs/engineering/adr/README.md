# Architecture Decision Records (ADR)

ADRs record important ALSM architecture decisions and why they were made.

## Status values

- Proposed
- Accepted
- Superseded
- Deprecated

## File naming

```text
ADR-001-short-kebab-title.md
ADR-002-short-kebab-title.md
```

Never renumber an accepted ADR. If a decision changes, add a new ADR and mark the old one `Superseded by ADR-xxx`.

## Required sections

```md
# ADR-xxx: Title

- Status:
- Date:
- Decision owners:

## Context

## Decision

## Consequences

### Positive
### Negative / Trade-offs

## Alternatives Considered

## Compliance / Implementation Notes

## Related Documents
```

ADRs explain **why**. `RULE.md` and engineering guides explain the enforceable current rules.
